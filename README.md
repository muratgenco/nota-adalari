# Nota Adaları

Piyano öğrencileri için nota okuma oyunları: Sol anahtarı, Fa anahtarı ve iki anahtar birlikte.
22 seviye, 4 mini oyun (Nota Bil, Piyano Tuşu, Notayı Koy, Hızlı Notalar), yıldızlar, çıkartmalar ve karne.
Mikrofon açıkken gerçek piyanoda çalınan notayı dinler.

Oyna: https://muratgenco.github.io/nota-adalari/
